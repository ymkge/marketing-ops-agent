# 03. Creative Pipeline (クリエイティブ生成パイプラインモジュール)

## 概要
広告クリエイティブ（バナー画像、広告コピー、SNS投稿文など）の制作を効率化・自動化するためのパイプラインモジュールです。n8n ワークフローや画像生成/言語モデルAPIと連携して動作します。

## 主な機能
- **コピー＆プロンプト自動生成**: ターゲット層・訴求軸ごとの広告コピーおよび画像生成用プロンプトの量産
- **画像生成API連携**: 画像生成モデル（DALL-E、Imagen、Midjourney等）を用いた素材生成
- **ワークフロー自動化**: n8nと連携した一連のレビュー・管理・通知プロセスの自動実行
