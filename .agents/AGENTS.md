# Agent Rules for marketing-ops-agent

## 開発・修正ワークフロー規約
案件の実装や修正を行う場合は、以下のルールを必ず遵守してください。

1. **実装計画書の提示とユーザー承認**:
   - 実装・修正前に必ず「実装計画書」を作成し、デグレやリスク情報、テスト方針をまとめてユーザーに提示する。
   - ユーザーから「OK」「進めてください」などの承認が得られるまで、実装を進めない。
2. **機能実装 & デグレ確認を含む自動テスト**:
   - 承認後に実装を行い、テスト機能を追加して自動テストを実行し、結果をまとめる。
3. **サブエージェントによる内部レビュー**:
   - 実装後にサブエージェントによる内部レビューを実施し、指摘事項をもとにブラッシュアップする。
4. **ウォークスルーの作成**:
   - ブラッシュアップ完了後、成果物・検証ログ・操作手順をまとめたウォークスルーを作成してユーザーに報告する。
