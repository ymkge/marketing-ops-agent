# 02. Report Automation (レポート自動化モジュール)

## 概要
広告媒体（Google, Meta等）やWebアナリティクス等のマーケティングデータを集計・加工し、LLMを活用した考察・インサイト付きの定例レポートを自動出力するモジュールです。

## 主な機能
- **データ集計・前処理**: `pandas` を利用した複数媒体データの統合とKPI集計
- **自動インサイト分析**: LLMによる実績変化の要因分析、改善アクション提案の生成
- **レポーティング出力**: Markdown/HTML/スライド形式などでの定期レポート出力連携

## ディレクトリ構成（予定）
```text
02_report_automation/
├── README.md
├── connectors/      # 各データソース連携
├── processors/      # データ加工・集計処理
├── analyzers/       # LLMインサイト生成
└── templates/       # レポート出力用テンプレート
```
